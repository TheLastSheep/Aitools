## Default Permission

Default permissions for the aitools Tauri plugin

#### This default permission set includes the following:

- `allow-search-features`
- `allow-zero-query-suggestions`
- `allow-run-agent-dag`
- `allow-resolve-hitl-step`
- `allow-invoke-legacy-list-feature`
- `allow-dsh-recent-logs`
- `allow-dsh-ingest-frontend-log`
- `allow-dsh-set-fault-injection`
- `allow-db-get`
- `allow-db-put`
- `allow-db-remove`
- `allow-db-all-docs`
- `allow-ai-chat`
- `allow-ai-embed`
- `allow-telemetry-log`
