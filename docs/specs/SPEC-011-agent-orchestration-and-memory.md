# SPEC-011: Ambient Context Stream, Multi-Tool DAG Orchestrator & Agent Memory

- **Status:** Active
- **Version:** 1.1.0
- **Owner Crates:** `crates/aitools-ai`, `crates/aitools-core`

## 1. Ambient Context Envelope & Zero-Query Intent Anchoring

- **SPEC-011-R1 (Structured Context Envelope):** Upon global hotkey wake (`SPEC-001`), `aitools-ai` MUST assemble a normalized `ContextEnvelope` within `2 ms` from `PreFocusContext` (`active_app`, `active_path`, `selection` with auto-detected `ContentSignature` / `ast_hint` for `json`, `url`, `stack_trace`, `sql`, `code`, `markdown`, `plain_text`, and `clipboard` preview).
- **SPEC-011-R2 (Zero-Query Action Recommendations):** Before the user types a character, `aitools-ai` MUST evaluate `ContextEnvelope` within `5 ms` to surface up to 3 pinned **Quick Agent Actions**.

## 2. Streaming Multi-Tool DAG Executor

- **SPEC-011-R3 (Bounded DAG Execution):** Multi-step tool calls generated by the LLM MUST be modeled as a Directed Acyclic Graph (`DagPlan`) capped at **max 8 nodes per turn** and **max depth 4** to prevent infinite agent loops.
- **SPEC-011-R4 (Parallel & Pipelined Scheduling):** Independent tool nodes at the same topological depth MUST execute concurrently via `tokio::task::JoinSet`. Dependent nodes receive upstream JSON outputs (`_upstream` map and `$node.<step_id>.output.<field>` interpolation).
- **SPEC-011-R5 (Suspend-and-Resume HITL Gate):** When a DAG node targets a `Tier1StateMutating` or `Tier2DestructiveOrExternal` tool (`SPEC-007-R7`):
  1. The executor MUST suspend that branch on a `tokio::sync::oneshot` channel with a `120 s` user-approval timeout.
  2. Emit an `HitlSuspended` event over the active `tauri::ipc::Channel`.
  3. Resume execution immediately upon approval, or abort downstream dependent nodes cleanly upon rejection/timeout.

## 3. Tiered Agent Memory & Workflow Solidification

- **SPEC-011-R6 (Session Scratchpad):** Active agent sessions maintain a bounded `SessionScratchpad` persisted in LMDB (`agent_memory` namespace).
- **SPEC-011-R7 (Workflow Macro Solidification):** Completed multi-tool DAGs MUST be serializable into deterministic `WorkflowMacro` records in LMDB (`agent_memory` namespace) and indexed directly into `SPEC-005` hybrid search (`to_feature_entry`) and `SKILL.md` (`to_skill_markdown`).
