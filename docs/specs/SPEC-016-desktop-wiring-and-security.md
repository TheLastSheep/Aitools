- **Status:** Active
- **Version:** 1.3.0
- **Owner Crates:** `crates/aitools-core`, `crates/aitools-native`, `crates/aitools-ai`, `crates/tauri-plugin-aitools`, `crates/aitools-cli`, `src-tauri`
- **Extends / Supersedes:** `SPEC-001` (Native Hooks), `SPEC-002` (Storage), `SPEC-006` (Desktop Shell & Capabilities — `SPEC-016-R4` tightens `SPEC-006-R2` guest permissions), `SPEC-007` (AI Platform), `SPEC-011` (Agent Orchestration), `SPEC-015` (3-Tier Preload Runtime)

## 1. Persistent AppData Storage & Startup Indexing

- **SPEC-016-R1 (Persistent AppData LMDB, Full Startup Indexing & Retina `128×128` Icon Cache):** `src-tauri` MUST open `StorageEngine` (`heed` LMDB) and chronological telemetry under the OS-native persistent `app.path().app_data_dir()` (NEVER `std::env::temp_dir()`). On startup, `src-tauri` MUST populate `FeatureSearchIndex`, `PluginMountRegistry`, and `ToolRegistry` from:
  1. Installed OS applications via `aitools_native::app_catalog::AppCatalog` (`.app` / `.desktop` / `.lnk` / `.exe`, resolving localized/display names, bundle IDs, and icons where available); on macOS, `AppCatalog::default_roots()` MUST include `/System/Cryptexes/App/System/Applications` (for Safari and Cryptex-hosted system apps) alongside `/Applications`, `/System/Applications`, and `~/Applications`.
     - `LauncherApp` MUST carry `#[serde(default, skip_serializing_if = "Option::is_none")] pub icon_path: Option<String>`, resolving macOS `.app/Contents/Info.plist` `CFBundleIconFile` / `CFBundleIconName` (probing `<name>`, `<name>.icns`, `<name>.png`, or the first non-template `.icns`/`.png` under `Contents/Resources/`).
     - `aitools_native::app_catalog::render_app_icon_png_128(source_path: &Path, cache_png_path: &Path) -> Result<()>` MUST render `.icns` and raster icon sources to `128×128` PNGs on macOS using `/usr/bin/sips -s format png -Z 128` into a temporary file followed by atomic rename (fast-copying or safely resizing PNG inputs, and returning a clear error/fallback on non-macOS).
     - Host icon registry (`PluginMountRegistry` / `AitoolsState`) MUST key each discovered macOS app icon or local plugin logo by a deterministic 16-character SHA-256 hex `<id>` (`icon_id -> PathBuf`), lazily materialize `128×128` PNGs under `<app_data_dir>/icon-cache/<id>.png`, and populate `icon: Some("aitools-plugin://__app_icon__/<id>.png")` on indexed `FeatureEntry` / `LauncherHit` items.
  2. Bundled built-in plugins under `plugins/builtin/*` (resolving both packaged Tauri bundle resources and dev workspace paths cleanly);
  3. Installed / synced ZTools plugin directories (including `<home>/.aitools/plugins/ztools` and paths registered via `sync_ztools_dir`) in strict read-only compliance with `INV-ZTOOLS-IMMUTABLE` (`SPEC-015-R1`).
  - Manifest indexing MUST synthesize searchable `FeatureEntry` items for both v1 `plugin.json` `features[]` and v2 `aitools.manifest.json` manifests (using explicit `features[]` or deriving a default entry from `id`, `name`, `description`, and `ai_tools`).
  - After startup indexing completes, `src-tauri` MUST retain the `TelemetryHandle`, emit a non-secret `tracing::info!` summary (`apps_indexed`, `plugins_indexed`, `plugin_features_indexed`; never logging raw secrets or clipboard contents per `INV-SEC-03`), rely on `RollingJsonlWriter` immediate per-record & `Drop` flushing, and explicitly flush telemetry on `"tray-quit"` and `RunEvent::Exit`.
  - `search_features` MUST return enriched `LauncherHit` items (`feature_code`, `plugin_id`, `label`, `plugin_name`, `description`, `icon`, `kind`, `score`, `match_type`, `confidence`, `explain`, plus optional `icon_is_dark`, `target_path`, `is_pinned`, `is_recommendation_pinned`, `use_count`) and execute `FeatureSearchIndex` text/Pinyin/regex/`over` matching plus typed `files` / `img` clipboard rules when active context carries file paths or image payloads (`SPEC-005-R4`).

## 2. Canonical Execution Pipeline, Host Launcher State, Icon Adaptation & Focus Guard

- **SPEC-016-R2 (Canonical 5-Kind Execution Dispatch, LMDB `"__host_launcher__"` State, `IconAdaptation`, `launcher_home_sections` & `PreloadRuntime` Session Wiring):** `tauri-plugin-aitools` and `aitools-native` MUST expose canonical host launcher capabilities aligned with ZTools (`packages/renderer-svelte`, `SPEC-017` v2.1.0):
  1. **LMDB `"__host_launcher__"` Host State Persistence (`crates/tauri-plugin-aitools/src/session.rs` & `session_ops.rs`):**
     - `PluginSessionManager` MUST persist launcher home and ranking state in `StorageEngine` under the reserved host namespace `"__host_launcher__"`:
       - `recent_history`: MRU list of `LauncherItemRef { plugin_id, feature_code }` capped at `36` entries; successful `launch_item` calls MUST prepend the launched item and clear any `removed_recent_keys` exclusion for it.
       - `pinned_items`: ordered list of `LauncherItemRef` entries displayed in `已固定`. When never initialized (`initialized: false`), the host MUST seed `pinned_items` once with curated built-in/installed items so `已固定` works out of the box, while persisting `initialized: true` so unpinning down to `[]` survives restarts without re-seeding.
       - `recommendation_pinned`: ordered list of `LauncherItemRef` entries (`(plugin_id, feature_code)`) for `匹配推荐` (`over` matches), strictly isolated from `pinned_items`.
       - `usage_stats`: map of `(plugin_id, feature_code) -> use_count` incremented on every successful `launch_item` execution and applied as tie-breaker (`use_count` descending) during search and recommendation ranking.
       - `removed_recent_keys`: exclusion set of `(plugin_id, feature_code)` keys explicitly removed via `remove_recent` so deleted entries stay hidden from `最近使用` across restarts until relaunched.
  2. **Pure-Rust Monochrome Icon Adaptation (`crates/aitools-native/src/icon_analysis.rs`):**
     - `aitools_native::icon_analysis` MUST implement zero-`unsafe`, panic-free `IconAdaptation { is_simple_icon, main_color, is_dark, needs_adaptation }` (`icon_is_dark_hint() -> Option<bool>`) plus `analyze_rgba_pixels`, `analyze_icon_bytes`, `analyze_icon_path`, and `analyze_icon_data_url` matching ZTools `src/main/api/shared/imageAnalysis.ts` exactly:
       - `total_pixels = width * height`, `step = (total_pixels / 1600).max(1)`, sampling byte stride `4 * step` (`a > 20` alpha threshold);
       - dominant RGB mode (`max_count` strict `>` tie-break), Euclidean RGB color distance `< 30.0`, `similarity_ratio > 0.85 && transparency_ratio > 0.10 && opaque_pixels > 20`;
       - W3C perceived luminance `(0.299 * r + 0.587 * g + 0.114 * b) / 255.0 < 0.5`.
     - `PluginSessionManager` MUST analyze both file-path icons (`aitools-plugin://__app_icon__/<id>.png`) and `data:image/...;base64,...` plugin icons, memoized in `icon_analysis_cache` keyed by SHA-256 (`system-apps` `.app` icons remain `icon_is_dark: None`).
     - `LauncherHit` (`crates/aitools-ai/src/launcher.rs`) MUST retain all 11 existing fields and add `#[serde(default, skip_serializing_if = "Option::is_none")]` optional fields: `icon_is_dark: Option<bool>`, `target_path: Option<String>` (canonical `.app` bundle or plugin root directory eligible for `打开文件位置`), `is_pinned: Option<bool>`, `is_recommendation_pinned: Option<bool>`, and `use_count: Option<u64>`.
     - `LaunchResult::ListMode` (`crates/tauri-plugin-aitools/src/session.rs`) MUST add `#[serde(default, skip_serializing_if = "Option::is_none")]` optional fields `plugin_icon: Option<String>` and `plugin_icon_is_dark: Option<bool>` for the unified single-input `SearchBox` tag.
  3. **Host-Only Home, Mutation, and Finder Commands (`build.rs`, `lib.rs`, `permissions/default.toml`):**
     - `featured_home_items(limit: Option<usize>) -> Result<Vec<LauncherHit>, String>` MUST remain exposed as a host-only command (`ensure_host_webview(webview.label())?`, `limit.unwrap_or(27).clamp(1, 54)`).
     - `launcher_home_sections(limit: Option<usize>) -> Result<HomeSectionsResponse, String>` MUST return `{ recent: Vec<LauncherHit>, pinned: Vec<LauncherHit>, featured: Vec<LauncherHit> }` enriched with `icon`, `icon_is_dark`, `target_path`, `is_pinned`, `is_recommendation_pinned`, and `use_count`.
     - `launcher_mutate_state(mutation: LauncherStateMutation) -> Result<HomeSectionsResponse, String>` MUST accept `#[serde(tag = "op", rename_all = "snake_case")]` mutations (`pin`, `unpin`, `reorder_pinned`, `remove_recent`, `pin_recommendation`, `unpin_recommendation`, `move_recommendation_to_front`), persist immediately to LMDB `"__host_launcher__"`, and return refreshed `HomeSectionsResponse`.
     - `reveal_in_finder(plugin_id: String, feature_code: String) -> Result<bool, String>` MUST resolve the canonical filesystem path strictly from `app_catalog` / `loaded_plugins` (never trusting arbitrary raw filesystem path strings) and invoke `/usr/bin/open -R` on macOS when the target path exists.
  4. **Canonical 5-Kind Execution Dispatch (`launch_item`, `search_list_mode`, `select_list_item`, `sync_ztools_dir`):**
     - `launch_item(feature_code, plugin_id, query, kind?, trace_id?, on_list_event)` MUST return a tagged `LaunchResult` (`opened_window`, `launched_app`, `list_mode`, `executed_headless`, `wasm_result`, `macro_started`) across all 5 item kinds:
       1. `app`: launches the native desktop application (`NSWorkspace` / `open` on macOS, `xdg-open`/spawn on Linux, `ShellExecute` on Windows) -> `launched_app`;
       2. `plugin` (UI): ensures `PluginMountRegistry` root registration, opens or focuses `plugin-<id>` via `build_plugin_window` (`INV-SEC-02`), activates `PreloadRuntime` when `"preload"` is present (injecting exported `window.*` proxies via `build_initialization_script_with_preload_props`), and dispatches `onPluginEnter` + `aitools:context-enter` (`ContextEnvelope`) -> `opened_window`;
       3. `list` / headless (`mode: "list" | "none" | "doc"`): acquires or initializes a `PluginSessionManager` session backed by `aitools_js_bridge::PreloadRuntime` (`SPEC-015-R2`), defaults to `PreloadExecutionMode::RustFirstWithFallback` (or `PreloadExecutionMode::PureRustOnly` when `AITOOLS_PURE_RUST_PRELOAD=1` / host config is set), derives `PreloadCapabilities { allow_fs, allow_net, allow_child_process }` strictly from the plugin manifest & trust tier, executes `enter`, streams initial `ListItem[]` over `Channel<ListPushEvent>`, and returns `list_mode` (including `plugin_icon` and `plugin_icon_is_dark`) or `executed_headless` for `none`;
       4. `wasm`: instantiates and invokes the Tier 3 `rust-wasm` module via `WasmPluginHost` (`SPEC-008-R3`, `SPEC-012-R3`) with zero child WebView -> `wasm_result`;
       5. `macro`: resolves and executes a saved `WorkflowMacro` DAG (`SPEC-011-R7`) through `PolicyGuard` -> `macro_started`.
     - `search_list_mode(session_id, plugin_id, feature_code, query, trace_id?, on_list_event)` MUST forward `SubInput` / launcher search updates to the active `PluginSessionManager` session and return `{ session_id, items }` while streaming `ListPushEvent` updates.
     - `select_list_item(session_id, plugin_id, feature_code, item, index, trace_id?)` MUST invoke `args.select` on the active preload session and return `{ ok, out_plugin?, hide_main?, message?, items? }`.
     - `sync_ztools_dir(dir_path?)` MUST scan `dir_path` (defaulting to `<home>/.aitools/plugins/ztools`) read-only (`INV-ZTOOLS-IMMUTABLE`), persist plugin records in LMDB, register mounts/features in `PluginMountRegistry` and `FeatureSearchIndex`, and return `{ dir, indexed_plugins, indexed_features, errors }`.

- **SPEC-016-R3 (Real Wake Context, Top-Edge-Anchored `800×58..594` Window Control, Tray Menu & `Focused(false)` Auto-Hide Guard):**
  - The `"main"` window in `src-tauri/tauri.conf.json` MUST initialize at `800×58` (`transparent: true`, `decorations: false`, `macOSPrivateApi: true`).
  - `src-tauri` MUST expose host-only `#[tauri::command] resize_main_window(height: f64)` (guarded by `ensure_host_webview(webview.label())?`), clamping `height` strictly to `58.0..=594.0` and resizing `"main"` to `LogicalSize::new(800.0, clamped)` while keeping its top screen edge fixed (`outer_position()` preserved, compensating if macOS adjusts window origin during `set_size`).
  - On global hotkey wake (`Alt+Space` and configurable `DoubleTapDetector`), `src-tauri` MUST capture real `PreFocusContext` (`app_name`, `bundle_id`, `window_title`, `selected_text` via Accessibility/AX or non-destructive fallback, `clipboard_preview`, `active_path`, `captured_at_ms`), assemble `ContextEnvelope`, position `"main"` horizontally centered and vertically ~`18%` down the active monitor height (`y`) so dropdown growth opens strictly downward, and stream `WakePayload` over `tauri::ipc::Channel` before showing `main`.
  - `src-tauri` MUST register a system tray icon (`tray-icon`) providing **Show Launcher**, **Developer Harness (DSH)**, and **Quit** actions so the app remains reachable even if global hotkey registration fails. Only the `"main"` WebView is instantiated eagerly in `tauri.conf.json`; **Developer Harness (DSH)** (`"tray-dsh"` and DSH hotkey) MUST lazily construct (or show/focus) the standalone `"dsh"` `WebviewWindow` (`/#dsh`, `960x640`) on demand via `open_or_focus_dsh_window`, preserving `"dsh"` permissions in `capabilities/main-shell.json`.
  - `WindowEvent::Focused(false)` on `main` MUST hide the launcher window ONLY when no active HITL confirmation, window drag, or modal guard is active (`!focus_hide_suppressed`), preventing mid-approval dismissal.

## 3. Capability Splitting, Network Gating & `NodeCompatGap` Observability (`INV-SEC-01`, `INV-SEC-02`)

- **SPEC-016-R4 (Guest Sandbox Capability Split, `webview.label()` Guards, `__app_icon__` Origin Allowlist, `http_op` & `PreloadTier` Telemetry):**
  1. **Least-Privilege `aitools:guest-sandbox` Permission (Supersedes `SPEC-006-R2` temporary `"aitools:default"` grant):** `crates/tauri-plugin-aitools/permissions/guest-sandbox.toml` (`identifier = "guest-sandbox"`) MUST authorize ONLY the 7 guest-scoped SDK commands: `db_get`, `db_put`, `db_remove`, `db_all_docs`, `ai_chat`, `ai_embed`, and `telemetry_log`.
  2. `src-tauri/capabilities/plugin-sandbox.json` (`"webviews": ["plugin-*"]`) MUST grant `"aitools:guest-sandbox"` (plus minimal `dialog:default`, `notification:default`, `opener:default`, and safe window/event scopes) and MUST NOT grant `"aitools:default"`.
  3. **Explicit `webview.label()` Guard on Every Privileged Host Command:** Every host-only command (`dsh_recent_logs`, `dsh_ingest_frontend_log`, `dsh_set_fault_injection`, `dsh_preload_status`, `run_agent_dag`, `resolve_hitl_step`, `submit_agent_prompt`, `launch_item`, `search_list_mode`, `select_list_item`, `sync_ztools_dir`, `invoke_legacy_list_feature`, `zero_query_suggestions`, `search_features`, `featured_home_items`, `launcher_home_sections`, `launcher_mutate_state`, `reveal_in_finder`, `resize_main_window`) MUST inspect `webview.label()` via `ensure_host_webview(webview.label())?` and reject any caller where `label.starts_with("plugin-")` with an explicit `forbidden (403)` error. `guest-sandbox.toml` MUST strictly exclude `"launcher-home-sections"`, `"launcher-mutate-state"`, `"reveal-in-finder"`, `"launcher_home_sections"`, `"launcher_mutate_state"`, `"reveal_in_finder"`, `"featured-home-items"`, `"featured_home_items"`, `"resize_main_window"`, and all other host-only commands.
  4. **Scoped `aitools-plugin://__app_icon__/<id>.png` Host Allowlist (`INV-SEC-01`):** In `protocols.rs` (`handle_plugin_asset_request`), `webview_label == "main"` or `webview_label == "dsh"` MAY read ONLY `aitools-plugin://__app_icon__/<16_hex>.png` when `<16_hex>` exists in the host's registered icon map. All `"plugin-*"` callers targeting `__app_icon__` and ALL non-`__app_icon__` hosts/paths from `"main"`, `"dsh"`, or cross-plugin origins MUST remain strictly rejected with HTTP `403`.
  5. **Manifest Permission Enforcement on `aitools-sync://` & `HostBridgeHandler::http_op`:**
     - `handle_sync_request` MUST verify `validate_sync_caller(webview_label, plugin_id)` (`INV-SEC-01`) AND enforce declared manifest `permissions` on sensitive domains (`clipboard.*`, `shell.*`, `db.*`, `ai.*`, `system.*`, `net.*`) for v2 manifests while preserving scoped ZTools compatibility defaults for v1 `plugin.json` manifests (never granting DSH or host agent privileges).
     - `HostBridgeHandler::http_op` MUST execute outbound HTTP/HTTPS requests in `crates/tauri-plugin-aitools` using `reqwest` (`rustls-tls`), strictly enforce `PreloadCapabilities::allow_net` / manifest network permissions, and emit `aitools-telemetry` tracing spans (`trace_id`, `plugin_id`).
  6. **`PreloadTier` & `node_compat_gap` Observability:** Active `PreloadTier` (`WebViewOnly` | `QuickJsNodeCompat` | `SystemNodeFallback`) per plugin and `aitools::node_compat_gap` counters MUST be exposed in DSH runtime state (`crates/tauri-plugin-aitools`) and aggregated by `aitools doctor` (`crates/aitools-cli`) so Node.js compatibility gaps are tracked until burned down to zero.

## 4. Schema Reconciliation, Keychain AI Broker & Streaming Agent DAG

- **SPEC-016-R5 (`Document` Envelope/Flat Reconciliation & `ContextEnvelope` Alignment):**
  - `aitools_core::Document` MUST seamlessly accept, persist, and serialize both flat PouchDB/ZTools documents (`{ "_id": "...", "_rev": "...", ...fields }`) and `{ "_id": "...", "_rev": "...", "data": { ... } }` envelope documents across `StorageEngine`, Tauri IPC (`db_*`), and `aitools-sync://` without dropping fields.
  - `aitools_ai::ContextEnvelope` and `@aitools/sdk`'s `ContextEnvelope` MUST share one aligned canonical schema covering `trace_id`, `app_name`, `bundle_id`, `window_title`, `selected_text`, `clipboard_preview`, `active_path`, `image_handle`, `captured_at_ms`, and `signature` (with backwards-compatible serde aliases where needed).

- **SPEC-016-R6 (Keychain HTTPS/SSE AI Broker & Real `submit_agent_prompt` DAG):**
  - `ModelBroker` MUST support named profiles `"fast"`, `"balanced"` (retaining `"reasoning"` alias compatibility for `SPEC-007`), `"deep"`, and `"embedding"`, resolving API keys solely from `aitools-native` `SecretStore` (`KeyringSecretStore`, `INV-SEC-03`).
  - `ai_chat` and `ai_embed` MUST execute real `reqwest` HTTPS/SSE requests for configured OpenAI-compatible and Anthropic providers (`parse_openai_sse_line` parsing `delta` tokens/tool calls prior to `finish_reason` so final deltas are never dropped), falling back cleanly to a clearly tagged deterministic `OfflineMock` response when no provider credential is configured.
  - `submit_agent_prompt(prompt, trace_id, chips, profile?, on_event)` MUST plan and execute multi-tool DAGs over live `ToolRegistry` providers (OS tools, built-in plugins, Wasm tools, legacy tools), sanitize untrusted ambient content (`PromptSanitizer` / `DangerousCommandGuard`), enforce `PolicyGuard` (`INV-SEC-04`, strictly requiring per-invocation explicit approval for `Tier2DestructiveOrExternal`), stream `AgentStreamEvent` variants (`token`, `thinking`, `node_started`, `hitl_suspended`, `node_completed`, `node_failed`, `completed`, `error`) over `tauri::ipc::Channel`, and return `{ trace_id, final_text, completed_nodes? }`.
